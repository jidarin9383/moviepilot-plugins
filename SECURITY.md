# Reporting a security issue

Do not open an issue containing cookies, API keys, Telegram sessions, login
QR codes, phone numbers, private share links, or unredacted runtime databases.
Use the maintainer's private GitHub contact channel when available. If no
private channel is available, open a minimal issue asking how to report privately,
without including the exploit payload or private data.

Provide affected versions and a synthetic reproduction. Do not upload your
MoviePilot configuration, `prowlarr.key`, `telegram.json`, cloud login files,
session databases, or an entire NAS deployment folder.
