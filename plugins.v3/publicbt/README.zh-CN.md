# 公开 BT 搜索（PublicBT）

[English](README.md) · [返回首页](../../README.md)

将 Prowlarr 的公开 BT 结果接入 MoviePilot 原生资源搜索，并使用独立下载器与专用目录。
支持 MoviePilot `>=3.2.4,<3.3.0`。

## 开始前

1. 部署 Prowlarr，只添加你需要的公开 BT 索引站。
2. 在 MoviePilot 中配置一个独立下载器，例如 `qb-public`。
3. 在 MoviePilot 目录设置中配置下载目录及整理规则。
4. 确认下载器和 MoviePilot 能访问同一组 NAS 路径。

服务地址示例：`http://prowlarr:9696`。下载目录示例：`/downloads/bt`。
这些只是示例，需要按自己的网络和容器挂载修改。

## 插件设置

| 分区 | 设置内容 |
|---|---|
| Prowlarr 连接 | 启用开关、完整服务地址、API Key |
| 搜索规则 | 索引站 ID、最低做种数、单次结果上限 |
| 下载路由 | 独立下载器的准确名称、NAS 绝对下载目录 |
| 使用记录 | 记录开关、最多保留数量 |

API Key 首次填写后会转存到插件数据目录的私密 `prowlarr.key` 文件，权限为 600。
页面不回显已保存的 Key，后续留空保存会保留；填写新值才会替换。

索引站 ID 使用英文逗号分隔；留空时搜索该 Prowlarr 实例的全部已配置索引站。
最低做种数默认 1；结果上限默认 100，允许 1–200。
电影和电视剧分别查询对应分类，搜索总等待时间最多 20 秒。

## 连接测试与下载

打开插件「更多 → 查看数据」，点击「测试连接」。该测试检查 Prowlarr 连通性与 API 认证，
不等于每个索引站都能正常搜索。测试结果和搜索结果都会记入使用记录。

手动下载时，请明确选择公开 BT 专用下载器。对于会回落到其他默认下载器、且无法可靠恢复路由的请求，
插件会阻止提交。你明确指定的其他下载器或目录会被保留。

「准备交接」发生在宿主正式提交之前，不是下载成功通知。
实际下载进度、完成状态和整理结果请查看 MoviePilot 原生下载管理与媒体整理页面。

## 使用记录

记录包含搜索结果、连接测试、路由准备、阻止提交及保留手动选择。
默认保留 1,000 条，可设为 1–5,000 条，支持刷新与翻页；时间显示为 UTC+08:00。
关闭记录不删除已有内容，不会补造安装前的历史。

记录不保存下载 URL、磁力链接、Key 或原始异常正文。
路由、端口、VPN、做种策略和整理规则仍由下载器或 MoviePilot 自身管理。
